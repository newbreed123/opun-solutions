# Opzix Product Documentation

This folder is the product source of truth for Opzix platform direction, reusable modules, and implementation strategy.

## Product Doctrine

Opzix is a platform company, not a page-build agency. Product work should strengthen reusable platform capabilities that can be configured for customer implementations.

BrittanyFlannigan.com should be treated as an in-progress real estate platform demonstration and reference design, not as a standalone custom website or the source of Opzix credibility.

## Working Principles

- Prefer reusable modules with customer configuration over one-off implementation logic.
- Do not over-engineer into a full multi-tenant SaaS before the platform needs it.
- Keep current implementation needs clear, especially where Brittany is used as an in-progress reference design.
- Use docs to clarify product intent before implementation details harden into code.
- Scanner validation rules remain separate from real estate product strategy.
