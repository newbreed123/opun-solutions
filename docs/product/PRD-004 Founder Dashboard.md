# PRD-004 Founder Dashboard

Version: 1.0

Status: Product Strategy

Owner: Opzix

## Purpose

The Founder Dashboard gives Opzix internal visibility into growth, product usage, Zora quality, scanner activity, scheduling, and operational signals.

## Goals

- Show acquisition and conversion trends.
- Reveal Zora learning opportunities.
- Track strategy call and scheduling performance.
- Summarize audit scanner usage and quality signals.
- Help prioritize product improvements.

## Core Views

- Acquisition metrics
- Funnel metrics
- Zora intelligence
- Scheduling metrics
- Scanner and audit activity
- Recent leads and conversations
- Product learning actions

## Product Rules

- Dashboard content should help the operator decide what to improve next.
- Internal views should avoid exposing unnecessary sensitive data.
- Zora learning should use sanitized summaries where possible.
- Real estate platform metrics should be added as reusable dashboard modules, not Brittany-only panels.

## Metrics

- Zora conversations
- Qualified leads
- Strategy call clicks
- Booked calls
- Audit completions
- Top industries
- Top concerns
- Low-confidence Zora responses
