# PRD-003 Analytics Platform

Version: 1.0

Status: Product Strategy

Owner: Opzix

## Purpose

The analytics platform connects marketing, website, AI, scheduling, scanner, and operational activity into decision-ready visibility.

## Goals

- Track full-funnel activity from traffic through booked appointments.
- Make lead quality and source attribution easier to understand.
- Connect Zora behavior with conversion outcomes.
- Support customer dashboards and internal founder dashboards.
- Provide reusable event foundations across industry implementations.

## Core Event Categories

- Page views
- CTA clicks
- Zora conversations
- Lead form submissions
- Audit scanner starts and completions
- Strategy call booking activity
- Real estate buyer inquiries
- Real estate seller inquiries
- Home valuation requests
- Dashboard usage

## Product Requirements

- Events should use stable names and structured payloads.
- Sensitive user data should be minimized in analytics.
- Dashboards should separate acquisition, engagement, conversion, and operations.
- Real estate events should distinguish buyer, seller, appointment, valuation, and property engagement intent.

## Metrics

- Traffic by source
- Lead conversion rate
- Booking completion rate
- Zora engagement rate
- Feature adoption
- Dashboard engagement
